## 2026-09-16 · API 3.0.0

本轮实现设计文档第一期学习闭环，不建设账号、鉴权、支付或第二期云数据库。

### 契约补充

- 学生档案、计划、任务、会话、题目及掌握度均由服务端持久化。响应统一使用 snake_case。
- 旧分析允许在生成计划时通过 `learner_id` 显式关联档案；多人同卷必须选择已关联具体 Paper 的学生，禁止混合多个学生的证据。
- 计划生成参数增加可选 `learner_id`。重新生成必须携带 `version` 及新的 `Idempotency-Key`，旧版计划及作答保留。
- `GET /api/learning-plans?learner_id=...` 提供学习中心计划列表；`GET /api/learners/{id}/history` 返回最近分析、计划和会话。
- 创建会话要求 `Idempotency-Key`。同一任务只能存在一个未结束会话，重试恢复原会话。
- `next_question` 仅包含题干、题型、知识点、层级和选项。参考答案和解析只在该题已批改的作答中返回。
- AI 出题按需生成，单批不超过三道。会话返回 `question_status=generating|ready|retryable`；GET 允许恢复尚未完成的出题和批改，服务重启后可继续。
- 作答先落库，主观题异步批改。客户端使用会话查询恢复最终结果；网络失败可按原 `client_attempt_id` 重试。
- 作答重试与会话结束携带 `version`。存在未完成批改时不能结束会话；`needs_review` 不计入有效作答或掌握度。
- 任务达标要求目标层级连续两题正确且达到建议题量；最多八次有效作答，连续两次错误进入需复习。建议题量是最低练习量，不替代达标规则。
- 单次掌握度变化限制在 ±8，基础/同构/迁移正确分别 +4/+6/+8，部分正确 +1，错误 -4/-6/-8。初始分析仅使用证据充分且已确认的题目；已有掌握度不会因计划重建被重置。
- 第一期计划由确定性模板生成；AI 负责受课程约束的练习生成与主观题批改。旧报告练习须经验证，默认按主观题处理，不能假设旧数组顺序代表难度。
- Android Room 升级采用增量迁移，作答队列保留原始输入和客户端编号；版本冲突展示可恢复状态，禁止静默换编号重提。
